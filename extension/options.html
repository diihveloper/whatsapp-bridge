WhatsApp Bridge Feeder

Watches the open WhatsApp Web tab and feeds your local whatsapp-bridge service. Keep a WhatsApp Web tab open for it to work.

Connection

Found in ~/.whatsapp-bridge/config.json under apiToken.

Status

Save your token, then refresh.

Contact aliases

A convenience map of name → JID so the assistant resolves people by name. Not a security control.

    Send whitelist sending off

    Read-only here by design. The whitelist is a security boundary, so it must be edited by you — run npm run wl or edit send_whitelist.txt in the project root (the service reloads automatically). Use the search below to find and copy the exact JID.

      Backfill history

      Re-fetch a chat's history into the database (e.g. before summarizing a conversation that arrived while the tab/service were down). Needs the WhatsApp Web tab open.
